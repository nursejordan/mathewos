# Mathewos — nurse-owned notary website

The whole site is one file: `index.html`. It is published at **mathewos.net** by Vercel.

## Updating the site
1. Open `index.html` on GitHub and click the pencil icon ✏️.
2. Change the text (prices, phone, wording).
3. Click **Commit changes**. Vercel republishes the site in about a minute.

## Vercel settings
- Framework Preset: **Other**
- Root Directory: **leave blank**
- Build Command / Output Directory: **leave empty** (there is nothing to build)
- Domains: `mathewos.net` and `www.mathewos.net`

## Booking buttons
"Text to book" buttons open a text message to (929) 866-0037. When you have an
online booking page, replace `sms:+19298660037` on those buttons with that link.
